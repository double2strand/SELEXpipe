# Data

Tracked example input is under [examples](examples/README.md).

`lig147_synthetic.fa` is a three-record FASTA for the length filter and the SEQ extract. It is not a sequencing run.

Sequencing inputs and pipeline products are gitignored: `raw/`, `processed/`, `motif_out/`, `*.fastq`, `*.fastq.gz`, `*.fq`, `*.fq.gz`, fastp `*.html` and `*.json` reports, and `*.seq` outside `data/examples/`.
